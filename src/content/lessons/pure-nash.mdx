# Pure-strategy Nash equilibrium

<p class="lead">A <span class="in-acc">Nash equilibrium</span> is a set of choices where no player can do better by changing their own move alone. Find it by looking for cells that are a best response for everyone at once.</p>

<DefinitionAside label="Nash equilibrium">
A profile $s^*$ is a Nash equilibrium if, for every player $i$, $u_i(s_i^*, s_{-i}^*) \ge u_i(s_i, s_{-i}^*)$ for all $s_i$. In words: given what everyone else does, no one has a profitable unilateral move.
</DefinitionAside>

This game has two pure equilibria, both-opera and both-football. Both players prefer coordinating to missing each other, but they disagree about which cell to land on.
</Section>

<Section id="key">
## Key idea

<Callout kind="key-idea">A Nash equilibrium is mutual best response, not group happiness. A game can have two, one, or none, and the stable outcome need not be the one everyone would pick together.</Callout>
</Section>
