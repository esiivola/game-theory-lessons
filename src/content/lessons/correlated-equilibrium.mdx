# Correlated equilibrium

<p class="lead">Nash equilibrium lets players randomize on their own, independently. But a shared signal, a light, a mediator, a public event, can correlate their choices, and that opens outcomes no independent play can reach. In Chicken, a coin the players cannot control does better for both than any Nash equilibrium.</p>

<Section id="chicken">
## The game: Chicken

Two drivers race head-on. Each can Swerve or go Straight. If both go Straight they crash (worst for both). If one swerves and the other does not, the one who held their nerve wins. Find the pure equilibria.

<Section id="why">
## Why did that happen?

<Callout kind="ask">
Independent mixing sometimes lands you both on Straight, which is the crash. A shared signal removes exactly that case: it recommends the three safe cells only, never the disaster. And you obey not because anyone forces you, but because, given what your recommendation tells you about the other driver, following it is your best reply. The correlation, not any enforcement, is what buys the extra payoff.
</Callout>
</Section>

<Section id="math">
## The math

Mixed Nash first. Let each driver go Straight with probability $q$. The opponent is indifferent when $6 - 4q = 7 - 7q$, so $q = \tfrac13$, and the value is $6 - 4\cdot\tfrac13 = \tfrac{14}{3} \approx 4.67$ each.

Now the mediator draws uniformly from the three cells that are not (Straight, Straight): $(\text{Sw},\text{Sw})$, $(\text{Sw},\text{St})$, $(\text{St},\text{Sw})$, and privately tells each player their part. Expected payoffs are

$$
\tfrac13(6) + \tfrac13(2) + \tfrac13(7) = 5 \quad\text{for each player},
$$

above the mixed Nash. For this to be an equilibrium, obeying must be a best response given what the recommendation reveals about the opponent.

<DefinitionAside label="correlated equilibrium">
A correlated equilibrium is a probability distribution over outcomes, run by a device that privately recommends a move to each player, such that no player can gain by deviating from their recommendation given the belief it induces about the others. Every Nash equilibrium is one (an uninformative device), but as here, some correlated equilibria beat every Nash equilibrium.
</DefinitionAside>
</Section>

<Section id="worked">
## Work it out

<WorkedExample title="Check that obeying is a best response">
Told **Swerve**: this happens in $(\text{Sw},\text{Sw})$ and $(\text{Sw},\text{St})$, so the opponent is equally likely to Swerve or go Straight. Obeying (Swerve) pays $\tfrac12(6) + \tfrac12(2) = 4$; deviating (Straight) pays $\tfrac12(7) + \tfrac12(0) = 3.5$. Obey.

Told **Straight**: this happens only in $(\text{St},\text{Sw})$, so the opponent surely swerves. Obeying (Straight) pays $7$; deviating (Swerve) pays $6$. Obey.

Both recommendations are self-enforcing, so the device is a correlated equilibrium, and it averages $(5,5)$, beating every Nash equilibrium of Chicken.
</WorkedExample>
</Section>

<Section id="key">
## Key idea

<Callout kind="key-idea">Let a shared signal correlate players' choices and you can reach outcomes independent randomization cannot. Obedience needs no enforcement, only that following the recommendation is each player's best reply.</Callout>
</Section>
