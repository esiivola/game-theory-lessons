# Zero-sum games and minimax

<p class="lead">In a strictly competitive game, whatever you win the other player loses. That sounds bleak, but it makes the game unusually clean: there is a single number, the value, that a careful player can guarantee no matter how cleverly the opponent plays. The way to guarantee it is to mix.</p>

<Section id="why">
## Why did that happen?

<Callout kind="ask">
If you commit to one flank, the defender guards it and you lose. If you mix, the defender cannot cover both, and there is one mix where guarding either flank leaves you the same expected gain. At that mix the defender has no good reply, so the payoff you get there is one you can guarantee whatever they do. That guaranteed number is the value of the game.
</Callout>
</Section>

<Section id="math">
## The math

<DefinitionAside label="zero-sum game">
A two-player game is zero-sum (more generally, constant-sum) if the payoffs in every cell add to the same constant, so one player's gain is exactly the other's loss. We can write it with a single payoff matrix to the row player; the column player earns its negative.
</DefinitionAside>

Let the raider play the strong flank with probability $p$. The guaranteed payoff against each defense is

$$
\text{vs guard-strong: } 1 - 2p, \qquad \text{vs guard-weak: } 3p - 1.
$$

The defender will pick whichever is worse for you, so your floor is $\min(1-2p,\,3p-1)$. That minimum is highest where the two lines meet:

$$
3p - 1 = 1 - 2p \quad\Rightarrow\quad p = \tfrac{2}{5}, \qquad \text{value} = 3\cdot\tfrac{2}{5} - 1 = \tfrac{1}{5}.
$$

<DefinitionAside label="von Neumann's minimax theorem">
In any finite two-player zero-sum game, the most the row player can guarantee (the maximin) equals the least the column player can hold them to (the minimax). That common number is the value of the game, and the mixes that achieve it form a Nash equilibrium. So here minimax is not pessimism: it is the equilibrium.
</DefinitionAside>

The defender solves the mirror problem and mixes $\tfrac35$ on guarding the strong flank, holding you to $\tfrac15$ from above. Maximin from below and minimax from above meet at the value.
</Section>

<Section id="worked">
## Work it out

<WorkedExample title="Find the value and the optimal mix">
Write the raider's guarantee against each pure defense as a line in $p$: guarding the strong flank yields $-p + (1-p) = 1 - 2p$; guarding the weak flank yields $2p + (-1)(1-p) = 3p - 1$. One line rises in $p$, the other falls, so their crossing is the highest floor.

Set $3p - 1 = 1 - 2p$ to get $p = \tfrac25$, and substitute back for a value of $\tfrac15$. Because the game is zero-sum, the defender's optimal mix guarantees the same value from the other side, so $\tfrac15$ is the value of the game, not just a floor.
</WorkedExample>
</Section>

<Section id="reality">
## A note from the real world

<Callout kind="reality-check">
Minimax mixing sounds like a blackboard ideal, too demanding for anyone under pressure. Yet it shows up in the field. Studying thousands of penalty kicks, Palacios-Huerta (2003) found professional kickers and keepers mix left and right at rates almost exactly matching the equilibrium, and in no readable order. The Behavioral unit returns to where this holds and where it breaks.
</Callout>
</Section>

<Section id="key">
## Key idea

<Callout kind="key-idea">In a zero-sum game there is one number you can guarantee, the value, and the mix that guarantees it is the equilibrium. Minimax play is not cautious here; it is optimal.</Callout>
</Section>
