# Optimal auctions

<p class="lead">Revenue equivalence said the format does not matter for revenue. But it took the rules as given. Myerson asked the harder question: across all mechanisms, which raises the most? The answer is clean. Run a second-price auction with a reserve set where the bidder's virtual value turns positive.</p>

<Section id="why">
## Why did that happen?

<Callout kind="ask">
The reserve is really a price you post to the winning bidder, and the right price to post to a single buyer with a uniform value is $1/2$, maximizing $p(1-p)$. Adding more bidders makes it more likely someone clears that bar and pushes up the price they actually pay through competition, so revenue rises. But the threshold itself, the point below which selling is not worth it, is a property of one bidder's value distribution, not of how many bidders there are. So the reserve stays put at $1/2$.
</Callout>
</Section>

<Section id="math">
## The math

<DefinitionAside label="virtual value and the optimal auction">
For a bidder with value $v$ and distribution $F$, the virtual value is $\psi(v) = v - \frac{1 - F(v)}{f(v)}$. Myerson's theorem: the revenue-maximizing auction allocates the item to the bidder with the highest virtual value, provided it is nonnegative, and charges accordingly. For regular distributions this is a second-price auction with a reserve $r$ solving $\psi(r) = 0$.
</DefinitionAside>

For the uniform distribution, $\psi(v) = 2v - 1$, so the reserve solves $2r - 1 = 0$, giving $r^* = \tfrac12$, independent of $n$. Intuitively, revenue is expected virtual surplus, and you only want to sell to a bidder whose virtual value is positive, that is, whose value clears $\tfrac12$.

With a single buyer, this is just posting a price $p$ to maximize $p(1-p)$, which peaks at $p = \tfrac12$ with revenue $\tfrac14$. Note the optimal auction sometimes does not sell (when every value is below the reserve), so revenue maximization is not the same as efficiency: the seller accepts occasional no-sales to keep prices up.
</Section>

<Section id="worked">
## Work it out

<WorkedExample title="Find the reserve, and see it ignore n">
The uniform virtual value is $\psi(v) = 2v - 1$. Set it to zero: $2r - 1 = 0$, so $r^* = \tfrac12$. This uses only one bidder's distribution, so it holds for any number of bidders.

Check the single-buyer case directly: posting price $p$ sells with probability $1-p$ for revenue $p(1-p)$, maximized at $p = \tfrac12$, revenue $\tfrac14$. Now add bidders. Competition raises the price the winner pays (toward the second-highest value), so expected revenue climbs with $n$, but the reserve that maximizes it stays at $\tfrac12$. Raising the reserve when bidders are plentiful would only forgo sales without helping, since the threshold is a fact about a single value draw.
</WorkedExample>
</Section>

<Section id="key">
## Key idea

<Callout kind="key-idea">The revenue-maximizing auction is a second-price auction with a reserve where the virtual value turns positive. For uniform values that reserve is 1/2, whatever the number of bidders, and it deliberately trades some efficiency for revenue.</Callout>
</Section>
