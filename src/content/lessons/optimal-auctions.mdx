# Optimal auctions

<p class="lead">Revenue equivalence said the format does not matter for revenue. But it took the rules as given. Myerson asked the harder question: across all mechanisms, which raises the most? With independent, risk-neutral bidders whose values come from a known regular distribution, allocate to the highest positive virtual value. For iid uniform values, that is a second-price auction with a reserve of $1/2$.</p>

<Section id="why">
## Why did that happen?

<Callout kind="ask">
In this iid-uniform model, the reserve is really a price you post to the winning bidder, and the right price to post to a single buyer is $1/2$, maximizing $p(1-p)$. Adding more bidders makes it more likely someone clears that bar and pushes up the price they actually pay through competition, so revenue rises. But the threshold itself is a property of one bidder's value distribution, not of how many bidders there are. So the reserve stays put at $1/2$. Change the distribution or the model, and the conclusion need not hold.
</Callout>
</Section>

<Section id="math">
## The math

<DefinitionAside label="virtual value and the optimal auction">
For a risk-neutral bidder with value $v$ and distribution $F$, the virtual value is $\psi(v) = v - \frac{1 - F(v)}{f(v)}$. In the independent-private-values model, Myerson's theorem allocates the item to the bidder with the highest nonnegative virtual value. For iid regular distributions, this is a second-price auction with a reserve $r$ solving $\psi(r) = 0$.
</DefinitionAside>

For the uniform distribution, $\psi(v) = 2v - 1$, so the reserve solves $2r - 1 = 0$, giving $r^* = \tfrac12$, independent of $n$. Intuitively, revenue is expected virtual surplus, and you only want to sell to a bidder whose virtual value is positive, that is, whose value clears $\tfrac12$.

With a single buyer, this is just posting a price $p$ to maximize $p(1-p)$, which peaks at $p = \tfrac12$ with revenue $\tfrac14$. Note the optimal auction sometimes does not sell (when every value is below the reserve), so revenue maximization is not the same as efficiency: the seller accepts occasional no-sales to keep prices up.
</Section>

<Section id="worked">
## Work it out

<WorkedExample title="Find the iid-uniform reserve">
The uniform virtual value is $\psi(v) = 2v - 1$. Set it to zero: $2r - 1 = 0$, so $r^* = \tfrac12$. This uses only one bidder's distribution, so it holds for any number of bidders.

Check the single-buyer case directly: posting price $p$ sells with probability $1-p$ for revenue $p(1-p)$, maximized at $p = \tfrac12$, revenue $\tfrac14$. Now add bidders. Competition raises the price the winner pays (toward the second-highest value), so expected revenue climbs with $n$, but the reserve that maximizes it stays at $\tfrac12$ in this iid-uniform model. A different value distribution can imply a different reserve.
</WorkedExample>
</Section>

<Section id="key">
## Key idea

<Callout kind="key-idea">For iid, risk-neutral bidders with regular values, the revenue-maximizing auction allocates to the highest positive virtual value. For uniform values, this is a second-price auction with a reserve of 1/2, whatever the number of bidders, and it deliberately trades some efficiency for revenue.</Callout>
</Section>
